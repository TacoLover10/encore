# Encore 🎵

A music player for the web, styled like a streaming app. It runs entirely on **GitHub Pages**: no server, no accounts, no API keys.

**Live:** https://tacolover10.github.io/encore/

## Features
- **Almost every song, full length.** Search plays official uploads through YouTube's embedded player. Search runs through free public Piped and Invidious mirrors and switches automatically if one is down.
- **Home shelves**: today's hits, hip-hop, pop, R&B, Latin, country, rock and throwbacks
- **Indie tab**: free tracks from independent artists on [Audius](https://audius.co)
- **My Files**: upload songs you own (MP3, M4A, FLAC, WAV, OGG), stored privately in your browser
- **Playlists**, **Liked Songs**, shuffle, repeat, keyboard shortcuts (Space, Shift+←/→)
- **Monthly Stats**: minutes listened, plays, top songs, top artists, minutes per day, peak hour, and a month picker. You can turn a month's top songs into a playlist.
- Export and import your data (Library → Backup)

## Notes
- YouTube requires its player to stay visible while it plays, so a small video box appears in the corner. Use ⤢ to make it bigger.
- Search depends on free community mirrors. If search says it's busy, wait a minute and try again.
- Your playlists and stats are saved in **your browser** on each device.
